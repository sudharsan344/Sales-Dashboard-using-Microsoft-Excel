# 📊 Excel Sales Dashboard

## Overview

Developed an interactive Sales Dashboard in Microsoft Excel to analyze and visualize sales performance using dynamic reports, advanced Excel features, and interactive dashboard components. The dashboard enables users to monitor key business metrics and gain actionable insights through data-driven analysis.

## Key Features

* Interactive Month, Category, and Region slicers
* KPI Cards for Total Sales, Total Profit, and Total Orders
* Sales analysis by Region, Category, Ship Mode, and Monthly Trends
* Dynamic Pivot Tables and Pivot Charts
* Professional dashboard layout with interactive filtering
